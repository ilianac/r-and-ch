# R&CH Logo System

This website now uses two complementary logo directions from the concept exploration.

## Primary — Modern Road Wordmark

File:

`assets/rch-wordmark.svg`

Use this for:
- Website header
- Email signatures
- Documents
- Invoices
- Horizontal signage

It preserves the road/arrow idea from the original R&CH identity but simplifies it for a cleaner modern look.

## Secondary — Shield / Movement Mark

File:

`assets/rch-shield.svg`

Use this for:
- Truck doors
- Social media avatar
- Uniforms
- Hats
- Stickers
- Favicon / app-style applications
- Website accents

The shield is intentionally treated as a secondary mark so the website stays clean rather than feeling like a badge-heavy trucking site.

## Important

These SVGs are clean starter vector interpretations of the selected concepts and can be edited later by a graphic designer. Because they are SVG files, they remain sharp at any size.
