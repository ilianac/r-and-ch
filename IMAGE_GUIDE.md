# Image Guide

The package currently includes crops from the approved website mockup so the website resembles the selected design immediately.

## Current image files

```text
assets/hero-van.jpg
assets/unit-01.jpg
assets/unit-02.jpg
assets/unit-03.jpg
```

The hero van uses the approved direction where the R&CH branding appears only near the front door rather than across the entire side of the van.

## Replacing with real photographs

When higher-resolution R&CH photos are available, simply overwrite the files using the same filenames.

Recommended:

### Hero

```text
hero-van.jpg
2400 × 1200 px or larger
Landscape
```

Best composition:
- Van moving or parked at an angle
- Entire van visible
- R&CH logo on door
- Clean highway / industrial / logistics background
- Leave some breathing room around the vehicle

### Fleet

```text
unit-01.jpg
unit-02.jpg
unit-03.jpg
```

Recommended:
- 1600 × 1000 px or larger
- Landscape
- Similar angle for all three
- Neutral / uncluttered backgrounds

You will not need to change the HTML or CSS if you keep these filenames.
